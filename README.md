# 🐾 Wildlife Conservation Website

## About the Project
The Wildlife Conservation Website is a beginner-friendly web development project created to spread awareness about wildlife protection, endangered species, and environmental conservation.

The website encourages people to protect animals, preserve forests, plant trees, and contribute towards a greener and healthier planet.

## 🎯 Objectives
- Spread awareness about wildlife conservation.
- Provide information about endangered species.
- Encourage tree plantation and environmental protection.
- Inspire people to take action to protect nature.

## 🛠️ Technologies Used
- **HTML5** – To create the structure of the website.
- **CSS3** – To style the website and make it attractive and responsive.
- **JavaScript** – To add basic interactivity.
- **YouTube Embed** – To display an environmental awareness video.

## ✨ Features
- Nature-inspired design.
- Wildlife conservation information.
- Endangered species section.
- Environmental awareness video.
- Responsive layout for different screen sizes.
- Interactive navigation and action form.
